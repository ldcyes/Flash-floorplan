# Flash-floorplan

**Flash-flooplanner: A Metal-Aware and Process-Scalable Floorplanning Framework for Early-Stage IC Architecture Exploration**

Interactive browser-based early-stage IC floorplanning and architecture exploration tool.

## Live demo

GitHub Pages: https://ldcyes.github.io/Flash-floorplan/

## Features

- Process-scalable block sizing across TSMC / Samsung / Intel / SMIC / GF / Huawei τ planning nodes
- Compute Core / Compute Cluster modeling with FLOPS/mm² and FLOPS/W inputs
- SRAM, UCIe, PCIe, DDR, LPDDR, HBM, GPIO, JTAG and analog/clock templates
- Router, arbiter, mux/demux, full crossbar and Beneš network estimation
- Metal-stack-aware routing capacity and congestion heatmap
- 1–3 tier W2W planning, bonding yield and cost estimation
- GPU beginner tutorial
- Chinese / English / Traditional Chinese / Japanese UI
- JSON / Draw.io / SVG / PNG / HD poster export
- Google Drive snapshot save/import support when OAuth is configured
